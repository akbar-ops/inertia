## 🧰 Built-In Tools and Integrations

inertia includes built-in tools that help the agent do practical work inside the desktop workspace. These tools are part of the application experience, so you can use them without writing code or setting up a development environment.

MCP, or Model Context Protocol, is a way for AI agents to connect to tools and data in a structured manner. In inertia, MCP integrations let your agent work with additional services and capabilities. OpenAPI integrations connect inertia to web services that provide an OpenAPI description. Together, these integration options make the workspace flexible without requiring you to build custom connectors.

If you already use external services, inertia gives you a place to bring them together. If you are new to integrations, start with chat and built-in tools first, then add connections as you become more familiar with the app.

## 🔐 Your Models and Keys

inertia follows a bring-your-own-model approach. That means you can use the AI model and provider you prefer, along with your own keys. This is useful if you already have an account with a model provider or if you want to keep your model choices separate from the desktop app.

In plain terms, a key is like a private password that lets inertia connect to your AI provider. You add your key inside the application where model settings are managed. You should keep your key private and avoid sharing it with others.

Because inertia supports multiple model providers and integration types, the workspace can adapt to different workflows. You can use one model for chat and later adjust your setup as your needs change.

## 🗂️ Routines and Memory

Routines help you repeat useful actions without starting from scratch each time. If you frequently ask an agent to perform the same kind of task, a routine can make that process easier to manage. Routines are useful for recurring checks, repeated research steps, regular writing tasks, and other activities that benefit from consistency.

Memory helps the agent retain helpful context. Instead of repeating the same background information in every conversation, memory gives the workspace a way to keep useful details available. This can make longer projects feel more continuous and reduce repetitive setup.

Together, routines and memory make inertia more than a simple chat window. They help the workspace support ongoing work over time.

## 🖥️ Live Desktop Sandboxes

inertia supports Docker and Daytona sandboxes with a live desktop view. A sandbox is a controlled environment where an agent can operate without affecting your main computer setup. The live desktop view lets you see what is happening inside that environment.

This is helpful when you want the agent to work with desktop applications, follow visual steps, or operate in a contained space. Sandboxes are especially useful for tasks that need a desktop-like environment but should remain separate from your everyday files and applications.

You do not need to be a developer to benefit from sandboxes. Think of them as a safe workspace inside the app where agent activity can be observed and organized.
